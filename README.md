# 하이컷팅건설 웹사이트 (Hi-Cuting)

간단한 원페이지 홍보 사이트로, 건설 컷팅/코킹 전문 업체 하이컷팅건설의 주요 서비스와 연락 정보를 담았습니다.

## 무엇을 보여주는 사이트인가요?

- 신축 줄눈 컷팅, 건식 컷팅, 코킹 전문 기술 소개
- 세 가지 원칙(하이, 하이, 하리)을 강조한 신뢰 포인트
- 현장 사진/도면 갤러리 및 빠른 전화/문자 문의 버튼
- 대표 연락처(010-5152-8003), 이메일, 사업자 정보

## 사용 기술

- HTML/CSS/JavaScript (정적 웹)
- Tailwind CSS CDN으로 빠른 스타일링
- Font Awesome 아이콘
- 로컬 style.css + script.js로 UI/상호작용 구현
- Gemini를 통한 바이브 코딩

## 주요 파일

- index.html : 전체 페이지 구조
- style.css : 사용자 정의 스타일
- script.js : 클립보드 복사, 모달, 갤러리 필터 동작
- assets/ : 로고, 이미지, 영상 등 자산

## 로컬 실행 방법

1. 프로젝트 폴더 열기
2. index.html을 브라우저로 열기
3. 또는 VS Code Live Server로 실행

## 목적

- 건설 서비스 홍보용 랜딩 페이지
- 고객 상담/견적 문의용 연락처 노출
- 빠르게 반응형으로 구성된 실무 포트폴리오 페이지
